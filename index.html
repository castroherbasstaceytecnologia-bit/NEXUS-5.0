Una señal acústica se transforma en una acción física: encender o apagar una luz mediante un circuito electrónico inteligente.

01 / DESCRIPCIÓN

Este proyecto utiliza un Arduino Uno conectado a un sensor de sonido y un módulo relé para controlar un LED de 9 voltios. Cuando el sensor detecta un sonido cercano que supera el umbral configurado, el sistema procesa la señal y cambia el estado de la iluminación.
